# React + Vite
# React Redux App 🚀

A modern frontend application built with **React**, **Vite**, **Redux Toolkit**, **Axios**, and **Tailwind CSS**.  
This project focuses on clean state management, API integration, and scalable frontend architecture.

---

## ✨ Features
- ⚡ Fast development using **Vite**
- 🧠 State management with **Redux Toolkit**
- 🔄 API integration using **Axios**
- 🎨 Responsive UI with **Tailwind CSS**
- 🔐 Secure environment variable handling
- 🧩 Reusable and modular components

---

## 🛠️ Tech Stack
- React
- Vite
- Redux Toolkit
- React Redux
- Axios
- Tailwind CSS
- JavaScript (ES6+)
